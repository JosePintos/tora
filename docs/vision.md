# Vision

A modern Japanese learning platform focused on active recall and spaced repetition, helping learners efficiently master vocabulary, kanji, and grammar through personalized study sessions.

## Goal

- Learn Go professionally
- Learn GraphQL
- Learn Hexagonal Architecture
- Learn AWS + Terraform
- Learn CI/CD
- Learn production software design
- Have a flagship portfolio project

## MVP

The app should allow users to

- Register
- Login
- Create decks
- Add vocabulary
- Study cards
- Track progress

## Target User

Initially:

> Myself.
> 

Later:

> Intermediate Japanese learners (JLPT N5-N2).
> 

## Future Features

- Grammar
- Kanji
- Furigana
- Audio
- Daily reminders
- AI-generated quizzes
- Mobile app
- Shared decks
- Leaderboards
